# Text File Analyser

A Python program that reads a `.txt` file, analyses its contents, and visualises the results using matplotlib.

## Features

- Reads any plain text file
- Counts words, lines and characters
- Finds the most frequent words
- Generates charts with matplotlib (e.g. a bar chart of the most common words)
- Handles errors such as missing or empty files

## Built With

- Python 3
- [matplotlib](https://matplotlib.org/)

## Getting Started

### Prerequisites

- Python 3.8 or higher
- pip

### Installation

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPO-NAME.git
cd YOUR-REPO-NAME
pip install matplotlib
```

### Running the project

```bash
python main.py yourfile.txt
```

## Example

```
Input:  sample.txt
Output: Words: 250 | Lines: 12 | Most common word: "the" (14)
```

A chart window opens showing the top words by frequency.
